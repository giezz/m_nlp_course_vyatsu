1. Описание¶

В ноутбуке демонстрируется классификация по тональности корпуса твитов о банках SentiRuEval-2015 с использованием модели ruRoBERTa-large от Сбера.

Исходные классы библиотеки transformers – RobertaForSequenceClassification и RobertaClassificationHead – модифицируются с целью организации выбора для классификации либо вектора первого токена (аналог токена [CLS]), либо среднего вектора по всем векторам выходных токенов.
За этот выбор отвечает параметр cls_token: True – если необходимо использовать первый токен, False – если нужно усреднение.

def replace_url(text, url_token):
    regex = r"(?i)\b((?:https?://|www\d{0,3}[.]|[a-z0-9.\-]+[.][a-z]{2,4}/)(?:[^\s()<>]+|\(([^\s()<>]+|(\([^\s()<>]+\)))*\))+(?:\(([^\s()<>]+|(\([^\s()<>]+\)))*\)|[^\s`!()\[\]{};:'\".,<>?«»“”‘’]))"
    
    replaced_text = re.sub(regex, url_token, text)
    
    return replaced_text

Токенизатор ruRoBERTa (и GPT-2) работает на основе байтов UTF-8, а не на основе символов. Это позволяет сократить базовый словарь до 256 символов (байт) (ссылка).

Символы кириллицы кодируются следующим образом:

  1. используется код символа в UTF-8, например, для буквы 'а' – D0B0 (два байта) (ссылка);
  2. эти два байта представляются в виде двух символов Unicode: 00D0 ('Ð') и 00B0 ('°') (ссылка);
  3. в результате буква 'а' кодируются символами 'Ð°'.

Если байт из кодировки UTF-8 в кодировке Unicode является управляющим (0080-00FF) (ссылка), например, код 0090 (ссылка), то к этому коду прибавляется шестнадцатеричное число 00A2.
Например, буква 'А' имеет код D090 в UTF-8. Первый байт представляется в виде символа 'Ð' (код Unicode 00D0), а второй байт является управляющим (0090), поэтому к нему прибавляется 00A2, получается 0132 (символ 'Ĳ').
Таким образом, буква 'А' представляется символами 'ÐĲ'.

Для декодирования токенов можно использовать класс ByteLevel из библиотеки tokenizers:

Как и в BERT, токенизатор ruRoBERTa разбивает слова, для которых нет отдельных токенов в словаре, на токены-подслова.
Особенностью токенизатора ruRoBERTa является то, что для токенов, входящих в состав некоторого слова, используется не признак '##' в начале токена, а отсутствие пробела (символ 'Ġ') в начале токена (ссылка1, ссылка2).
Например, строка 'мама мыла раму' разделится на следующие токены:

  • 'Ð¼' – 'м'
  • 'Ð°Ð¼Ð°' – 'ама' (в начале нет символа-пробела)
  • 'ĠÐ¼ÑĭÐ»Ð°' – ' мыла' (в начале есть символ-пробел)
  • 'ĠÑĢÐ°Ð¼' – ' рам' (в начале есть символ-пробел)
  • 'Ñĥ' – 'у' (в начале нет символа-пробела)

    '''Функция для входного Dataframe возвращает список размеров текстов в токенах'''

8. Создание классов¶

Новый класс RobertaFineTuningClassificationHead¶

За основу взят класс RobertaClassificationHead (ссылка).

В этом классе к выходу модели добавляется двухслойная нейронная сеть.

Изменения в этом классе:

  • добавлено поле self.cls_token = config.cls_token;
  • в методе forward добавлена проверка поля self.cls_token.
In [ ]:
class RobertaFineTuningClassificationHead(nn.Module):
    """Head for sentence-level classification tasks."""

    def __init__(self, config):
        super().__init__()
        self.cls_token = config.cls_token
        self.dense = nn.Linear(config.hidden_size, config.hidden_size)
        classifier_dropout = (
            config.classifier_dropout if config.classifier_dropout is not None else config.hidden_dropout_prob
        )
        self.dropout = nn.Dropout(classifier_dropout)
        self.out_proj = nn.Linear(config.hidden_size, config.num_labels)

    def forward(self, features, **kwargs):
        if self.cls_token:
            x = features[:, 0, :]  # take <s> token (equiv. to [CLS])
        else:
            x = torch.mean(features, dim=1) # average all the tokens
        x = self.dropout(x)
        x = self.dense(x)
        x = torch.tanh(x)
        x = self.dropout(x)
        x = self.out_proj(x)
        return x

Новый класс RobertaForFineTuningClassification¶

За основу взят класс RobertaForSequenceClassification (ссылка]).

Единственное изменение в этом классе – заменен классификатор self.classifier: вместо класса RobertaClassificationHead использован новый класс RobertaFineTuningClassificationHead.

class RobertaForFineTuningClassification(RobertaPreTrainedModel):

    def __init__(self, config):
        super().__init__(config)
        self.num_labels = config.num_labels
        self.config = config

        self.roberta = RobertaModel(config, add_pooling_layer=False)
        self.classifier = RobertaFineTuningClassificationHead(config)

        # Initialize weights and apply final processing
        self.post_init()

    def forward(
        self,
        input_ids=None,
        attention_mask=None,
        token_type_ids=None,
        position_ids=None,
        head_mask=None,
        inputs_embeds=None,
        labels=None,
        output_attentions=None,
        output_hidden_states=None,
        return_dict=None,
    ):
        r"""
        labels (:obj:`torch.LongTensor` of shape :obj:`(batch_size,)`, `optional`):
            Labels for computing the sequence classification/regression loss. Indices should be in :obj:`[0, ...,
            config.num_labels - 1]`. If :obj:`config.num_labels == 1` a regression loss is computed (Mean-Square loss),
            If :obj:`config.num_labels > 1` a classification loss is computed (Cross-Entropy).
        """
        return_dict = return_dict if return_dict is not None else self.config.use_return_dict

        outputs = self.roberta(
            input_ids,
            attention_mask=attention_mask,
            token_type_ids=token_type_ids,
            position_ids=position_ids,
            head_mask=head_mask,
            inputs_embeds=inputs_embeds,
            output_attentions=output_attentions,
            output_hidden_states=output_hidden_states,
            return_dict=return_dict,
        )
        sequence_output = outputs[0]
        logits = self.classifier(sequence_output)

        loss = None
        if labels is not None:
            if self.config.problem_type is None:
                if self.num_labels == 1:
                    self.config.problem_type = "regression"
                elif self.num_labels > 1 and (labels.dtype == torch.long or labels.dtype == torch.int):
                    self.config.problem_type = "single_label_classification"
                else:
                    self.config.problem_type = "multi_label_classification"

            if self.config.problem_type == "regression":
                loss_fct = MSELoss()
                if self.num_labels == 1:
                    loss = loss_fct(logits.squeeze(), labels.squeeze())
                else:
                    loss = loss_fct(logits, labels)
            elif self.config.problem_type == "single_label_classification":
                loss_fct = CrossEntropyLoss()
                loss = loss_fct(logits.view(-1, self.num_labels), labels.view(-1))
            elif self.config.problem_type == "multi_label_classification":
                loss_fct = BCEWithLogitsLoss()
                loss = loss_fct(logits, labels)

        if not return_dict:
            output = (logits,) + outputs[2:]
            return ((loss,) + output) if loss is not None else output

        return SequenceClassifierOutput(
            loss=loss,
            logits=logits,
            hidden_states=outputs.hidden_states,
            attentions=outputs.attentions,
        )

def compute_metrics(pred):
    '''Функция возвращает метрики качества'''
    labels = pred.label_ids
    preds = pred.predictions.argmax(-1)
    precision, recall, f1, _ = precision_recall_fscore_support(labels, preds)
    acc = accuracy_score(labels, preds)
    return {
        'accuracy': acc,
        'f1_mean': np.mean(f1),
        'f1': f1.tolist(),
        'precision': precision.tolist(),
        'recall': recall.tolist()
    }
